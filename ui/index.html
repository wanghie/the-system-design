Giao diện The System

Xương sống: IKIGAI + một hình mẫu lý tưởng → tạo ra một nhân vật → thiết kế cuộc đời bám mục tiêu → trở thành nhân vật lý tưởng. Mọi quest/focus/event đều để rút ngắn khoảng cách giữa bạn-hiện-tại và nhân-vật-lý-tưởng. Aesthetic: game HUD Status Window (dark + cyan glow), sạch như tracker. Mỗi màn ghi rõ pattern lấy từ 6 app đã bóc. Import Figma bằng html.to.design.
