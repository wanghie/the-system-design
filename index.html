Design files — cho Figma

Deck nghiên cứu UX/UI đối thủ + prototype app. Import vào Figma bằng plugin html.to.design (nhập URL bên dưới).

Đưa vào Figma (3 bước)

  1. Mở Figma → chạy plugin html.to.design → chọn Import from URL
  2. Dán URL của deck (bấm mở deck bên dưới rồi copy link trên thanh địa chỉ)
  3. Plugin dựng thành frame Figma sửa được → kéo screenshot thật vào ô mockup
